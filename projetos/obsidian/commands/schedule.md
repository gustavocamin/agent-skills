---
description: Cria um calendário de blocos de tempo a partir de prioridades e compromissos do vault
argument-hint: [amanhã | próximos N dias] (opcional)
---

Use a Skill tool para invocar a skill `daily-operations` com args `/schedule $ARGUMENTS`. Siga exatamente as instruções dessa skill para o comando `/schedule`.

Nota: este comando é sobre planejar blocos de tempo do dia a partir do vault — diferente de agendar tarefas/agentes recorrentes do Claude Code.
